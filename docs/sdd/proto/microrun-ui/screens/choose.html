microrun: який підхід до інтерфейсу?

Кожен варіант — робочий: клікайте по оточеннях, відкотіть production (введіть «production»), пройдіть прибирання даних, відкрийте історію. Дані однакові в усіх трьох.

A

Таблиця + модальне вікно

Огляд карток → сторінка оточення з таблицею релізів → відкат у модалці. Звично й щільно; вся інформація про реліз в одному рядку. Мінус: модалка тісна для cleanup з багатьма правилами.

Відкрити A →

B

Колонки оточень + бічна панель

dev, stage, production поруч таймлайнами на одному екрані; деталі й відкат — у панелі праворуч. Видно все й одразу порівнювати оточення. Мінус: на вузькому екрані колонки стають у стовпчик, а production легко «загубити» знизу.

Відкрити B →

C

«Зараз працює» + майстер відкату

Бічне меню оточень, великий блок поточного релізу, відкат — покроковий майстер на всю сторінку (ціль → підтвердження → виконання → прибирання → підсумок). Найважче помилитися. Мінус: більше кліків, немає загального огляду всіх оточень на одному екрані.
