# microrun — implementation plan

**Goal:** a working microrun v1 as specified: the Docker image `microrun/microrun` (Fastify server, SSR+htmx UI in 8 languages, SQLite, scheduler, built-in agent) and the npm package `microrun` (`microrun agent`, `microrun deploy`). Releases of Docker Compose apps can be deployed through a gate, rolled back in ≤ 60 s without DDL, and cleaned up.
**Spec:** docs/sdd/specs/2026-11-22-microrun.md
**Prototype:** docs/sdd/proto/microrun-ui/decision.md (variant D2 — `docs/sdd/proto/microrun-ui/variants/d2/index.html`, `shared/i18n.js` are the visual and i18n reference)
**Verification:** `pnpm verify` (= `pnpm -r build && pnpm test && pnpm test:docker && pnpm test:e2e`); expected last line: `  N passed (…)` from Playwright, with no failed tests in any step.
**Worktree:** /home/pc/projects/microrun-spec, branch `feat/microrun-spec`. No git remote, so there is no PR and no PR comments.
**Duplication check (`ub-tools dryer`):** not applicable. This is a greenfield repository with no source files yet.

## Context

The repository holds only the approved spec and the UI prototype. This plan builds the product from scratch as a pnpm monorepo with three packages. Pure domain logic sits in `core`, so the server and the agent share one state machine, one protocol and one set of i18n catalogs.

## Global constraints

- Node.js 26 (local `v26.4.0`); pnpm 11 (`packageManager: "pnpm@11.22.0"`); TypeScript `^7.0.2` with `strict`, `module`/`moduleResolution: "NodeNext"`, ESM only (`"type": "module"`).
- Test runner: vitest `^5.1.1`. Docker-dependent tests are named `*.docker.test.ts` and run only under `pnpm test:docker`. E2E uses `@playwright/test ^1.65.1` under `e2e/`.
- Pinned dependencies:
  - Runtime: fastify `^5.12.8`, @fastify/websocket `^11.3.7`, @fastify/cookie `^11.1.5`, @fastify/formbody `^9.0.2`, @fastify/rate-limit `^11.3.0`, @fastify/static `^10.1.12`, knex `^3.3.0`, better-sqlite3 `^13.2.0`, zod `^4.6.7`, ws `^8.23.0`, @aws-sdk/client-s3 and @aws-sdk/lib-storage `^3.1175.0`, htmx.org `^2.0.11`.
  - Build and tooling: tsup `^9.0.0`, tsx `^4.23.15`, @types/node `^26.6.6`.
- **No code comments** unless they record a constraint the code cannot show (AGENTS.md). Never narrate.
- Use the names from the spec verbatim: table and column names (3.3), result codes (3.6), CLI flags (3.5), ENV names (3.13), `_microrun_env`, `docker-compose.microrun.yml`, `microrun-proxy`, `microrun-dryrun-<op>`, and the `MICRORUN_*` variables passed to commands.
- Every timestamp is Unix ms (`number`). Every function that needs the time takes `now: number` or a `Clock = () => number`. Code never calls `Date.now()` directly, except in `main.ts`.
- Secrets never appear in logs or in `operations.log`. Commands that carry credentials redact them as `***` before logging.
- User data rendered in HTML is always escaped (the `html` tagged template from Task 12). i18n params are escaped by `t()`.
- Each task writes only its **Writes** files. A missing helper is not added to another task's file: it lives in the task's own file.

## Review Focus

1. Two CI deploys of different commits hit the same environment within milliseconds. Exactly one gets `pending` and the other gets `409 ENV_BUSY`, enforced by the partial unique index and not by code. Test owner: Task 9.
2. The agent restarts in the middle of a rolling switch, leaving 2N containers. On resume, `switchServices` for the same `(opId, step)` finishes the switch (stops the old containers) instead of scaling to 4N. Test owner: Task 14.
3. A retention boundary exactly at `now − superseded_at == retention_s*1000` makes the release expire, and a boundary one ms earlier does not. Test owner: Task 2.
4. `cleanup --dry-run` prints non-JSON lines, a JSON line with a wrong shape, and lines longer than 64 KiB. Valid lines are parsed, the rest go to the log, and nothing throws. Test owner: Task 15.
5. A `mr_lang` cookie set to an unsupported value (`xx`, `../`) falls back to `Accept-Language`, then to `en`. Test owner: Task 5.

### Task 2: core state machine and retention/contract rules

**Writes:** `packages/core/src/state.ts`, `packages/core/src/state.test.ts`
**Depends on:** Task 1
**Executor:** claude
**Complexity:** complex
**Interfaces:**
- Produces (`@microrun/core/state`):
  ```ts
  export type ReleaseState = 'active'|'available'|'blocked'|'expired'|'failed';
  export type CleanupState = 'none'|'pending'|'applied'|'dismissed'|'lapsed';
  export interface ReleaseFacts { id: string; commitSha: string; state: ReleaseState; deployedAt: number;
    supersededAt: number|null; activationSeq: number|null; blockedAt: number|null; imagePurgedAt: number|null;
    contractedAt: number|null; cleanupState: CleanupState; hasCleanupCmd: boolean }
  export type ReleasePatch = { id: string; patch: Partial<ReleaseFacts> };
  export type DeployDecision = { kind: 'new' } | { kind: 'already_active'; releaseId: string }
    | { kind: 'reactivate'; releaseId: string } | { kind: 'redeploy'; releaseId: string }
    | { kind: 'reject'; code: 'COMMIT_BLOCKED'|'COMMIT_EXPIRED'; releaseId: string };
  export function decideDeploy(rs: ReleaseFacts[], commitSha: string): DeployDecision;
  export function onDeploySuccess(rs: ReleaseFacts[], releaseId: string, now: number): ReleasePatch[];
  export function planRollback(rs: ReleaseFacts[], targetId: string): { block: string[] } | { error: 'TARGET_NOT_AVAILABLE' };
  export function onRollbackSuccess(rs: ReleaseFacts[], targetId: string, now: number): ReleasePatch[];
  export function dueExpiry(rs: ReleaseFacts[], retentionMs: number, now: number): { expire: string[]; purge: string[] };
  export function nextContract(rs: ReleaseFacts[]): string | null;
  export function closeWindow(rs: ReleaseFacts[], releaseId: string): string[];
  export function onDestructiveApproved(rs: ReleaseFacts[]): string[];
  export function windowLeftMs(r: ReleaseFacts, retentionMs: number, now: number): number | null;
  export function lapseCleanup(rs: ReleaseFacts[]): string[];
  ```
- Semantics (spec 3.4, 3.9, 3.10):
  - `decideDeploy` by state of the release with `commitSha`: none → new; active → already_active; available → reactivate; failed → redeploy; blocked → reject COMMIT_BLOCKED; expired → reject COMMIT_EXPIRED.
  - `onDeploySuccess`: the target gets `state:'active'`, `activationSeq = max(seq)+1`, `supersededAt:null`. The previous active gets `available`, `supersededAt: now`.
  - `planRollback`: the target must be `available`. `block` is the active release plus every available release with `activationSeq > target.activationSeq`.
  - `onRollbackSuccess`:
    - every release in `block` gets `state:'blocked'`, `blockedAt: now`, and `cleanupState:'pending'` when `hasCleanupCmd`;
    - the target gets `active`, `activationSeq = max+1`, `supersededAt: null`.
  - `dueExpiry`:
    - `expire` = available releases where `now - supersededAt >= retentionMs`;
    - `purge` = releases with `imagePurgedAt === null` that are either `expired` (including those just expiring) or `blocked` with `now - blockedAt >= retentionMs`.
  - `nextContract`:
    - candidates are releases with state in active|available|expired and `contractedAt === null`, sorted by `deployedAt`;
    - the first candidate qualifies if every release with a smaller `deployedAt` is in expired|blocked|failed and none of them has `cleanupState === 'pending'`;
    - only the oldest qualifying candidate is returned, otherwise `null`.
  - `closeWindow`: the ids of available releases with `deployedAt < target.deployedAt`.
  - `onDestructiveApproved`: the ids of every available release.
  - `lapseCleanup`: the ids of blocked releases with `cleanupState==='pending'` and `imagePurgedAt !== null`.

### Task 3: core schema snapshot, normalization and diff classifier

**Writes:** `packages/core/src/schema.ts`, `packages/core/src/schema.test.ts`
**Depends on:** Task 1
**Executor:** claude
**Complexity:** complex
**Interfaces:**
- Produces (`@microrun/core/schema`):
  ```ts
  export type DbKind = 'postgres'|'mysql'|'sqlite'|'mongodb';
  export interface Column { name: string; type: string; nullable: boolean; default: string|null }
  export interface Index { name: string; columns: string[]; unique: boolean }
  export interface SqlSnapshot { kind: 'sql'; engine: 'postgres'|'mysql'|'sqlite'; tables: { name: string; columns: Column[]; indexes: Index[] }[] }
  export interface MongoSnapshot { kind: 'mongo'; collections: { name: string; indexes: { name: string; keys: Record<string, number|string>; unique: boolean }[]; validator: unknown|null }[] }
  export type SchemaSnapshot = SqlSnapshot | MongoSnapshot;
  export interface DiffEntry { kind: 'add'|'warn'|'drop'; object: string; detail: string }
  export const snapshotSchema: z.ZodType<SchemaSnapshot>;
  export function normalizeType(engine: 'postgres'|'mysql'|'sqlite', raw: string): string;
  export function normalizeDefault(raw: string|null): string|null;
  export function diffSchema(base: SchemaSnapshot, next: SchemaSnapshot): DiffEntry[];
  export function isDestructive(d: DiffEntry[]): boolean;
  export function sameDestructive(a: DiffEntry[], b: DiffEntry[]): boolean;
  ```
- Normalization:
  - lower-case and collapse whitespace;
  - postgres: `character varying(n)`→`varchar(n)`, `character varying`→`varchar`, `integer`→`int`, `int4`→`int`, `int8`/`bigint`→`bigint`, `int2`/`smallint`→`smallint`, `timestamp with time zone`→`timestamptz`, `boolean`→`bool`;
  - mysql: strip `int(11)` display widths (`int(11)`→`int`);
  - sqlite: map to affinity (`INTEGER`, `TEXT`, `REAL`, `NUMERIC`, `BLOB` per SQLite affinity rules).
