# UI polish — implementation plan

**Goal:** the login page follows prototype B3. Every form uses one Tailwind/Flowbite-style control set from `ui/form.ts`. Settings can delete a remote server that has no environments, and an idle environment. English is listed first and is the default web language. The login page has a language switch.
**Spec:** docs/sdd/specs/2026-11-22-ui-polish.md
**Prototype:** docs/sdd/proto/login/decision.md

## Global constraints

- Styling uses Tailwind v4 utilities in the `html` templates. Plain CSS lives only in `packages/server/src/public/app.src.css` (Task 1), for what utilities cannot reach: `#panel` and `body:has(#panel…)`, the `.tl` / `.rel::before` timeline pseudo-elements, and the `led` keyframes.
- **Never build a class name by interpolation** (`text-${c}`). Tailwind only sees complete literal class strings in `src/ui/**/*.ts`. Pick from literal maps instead.
- Never put a display utility (`flex`, `grid`, `block`) directly on a `<dialog>`, because it beats the UA's `dialog:not([open]){display:none}`. On elements that carry a `hidden` attribute, use `[&:not([hidden])]:grid` instead of a bare `grid`.
- Keep every existing `data-testid`, `name`, `id="username"` / `id="password"`, `data-status`, `data-ok`, `data-kind` and `aria-label`.
- `form.select` and `form.input` emit `name` as the first attribute (`settings.test.ts:430` asserts `<select name="proxy_mode"`).
- No comments in code unless they record a hidden constraint (user rule).
- Colour tokens and their values come from Task 1. Use the utilities `bg-bg bg-surface bg-card bg-field text-ink text-mute border-line bg-accent text-on-accent ring-ring text-prod bg-prod-soft text-ok text-warn bg-warn-soft bg-code`, plus `*-console-{bg,ink,mute,line,ok,accent,warn}` on the login panel.
- The `ui` catalog calls environments «оточення». New Ukrainian strings use that word too.
- Old class → utilities map. Wave 2 tasks use it so the app keeps its current look:

## Review Focus
1. A server or environment name with `&"<` appears in the dialog title, `data-name` and the error text. It must be escaped, and the exact raw name still confirms → test in Task 7a (view) and Task 7b (route).
2. A double-submitted delete: the second POST returns 404 and leaves nothing half-deleted → Task 7b.
3. An environment whose release has `blocked_by_op` pointing at its own operation: the delete order must not trip the foreign key → Task 3.
4. `GET /login?lang=de&lang=uk` (an array) or `?lang=../`: ignored, no cookie, English → Task 5.
5. The rebind after an orphan marker writes a new marker id. The next deploy's `checkMarkers` accepts it → Task 4.

- `field(p: { id: string; label: Html; control: Html; hint?: Html; error?: Html; caps?: boolean })`

- `input(p: { name: string; id?: string; value?: string; type?: 'text'|'password'|'number'|'url'; required?: boolean; autocomplete?: string; placeholder?: string; testid?: string; invalid?: boolean; cls?: string; attrs?: Html })`
  - `name` comes first; no `value` attribute when `value` is undefined;
  - class: `CONTROL` (+ ` border-prod` when invalid, + `cls`).
- `textarea(p: { name: string; id?: string; value?: string; rows?: number })` — `CONTROL font-mono`, rows default 3.
- `select(p: { name: string; id?: string; options: { value: string; label: Html|string }[]; current?: string; testid?: string; compact?: boolean; attrs?: Html })`
  - `<select name=… [id] [data-testid] class=…[attrs]>` with `<option value="v"[ selected]>`;
  - compact class: `rounded-md border border-line bg-field py-1.5 pl-2.5 pr-8 text-sm text-ink focus:border-accent focus:outline-none focus:ring-4 focus:ring-ring`.
- `checkbox(p: { name: string; id?: string; checked: boolean; label?: Html; attrs?: Html })`
  - the input has class `size-4 rounded border-line accent-accent focus:ring-2 focus:ring-ring`;
  - with a label, it is wrapped in `<label class="inline-flex items-center gap-2 text-sm text-ink">`.
- `button(p: { label: Html; variant?: 'primary'|'danger'|'ghost'; type?: 'submit'|'button'; testid?: string; disabled?: boolean; block?: boolean; attrs?: Html })`
  - base: `inline-flex items-center justify-center rounded-md px-4 py-2.5 text-sm font-semibold focus:outline-none focus-visible:ring-4 focus-visible:ring-ring disabled:cursor-not-allowed disabled:opacity-40`;

  async findEnvByMarker(markerId: string): Promise<EnvRow | null> {
    return firstOf<EnvRow>(this.db('environments').where({ db_marker_id: markerId }), ENV);
  }
  async countEnvsOnServer(serverId: string): Promise<number> {
    const row = (await this.db('environments').where({ server_id: serverId }).count({ n: '*' }).first()) as { n: number | string } | undefined;
    return Number(row?.n ?? 0);
  }
  async deleteServer(id: string): Promise<'deleted' | 'builtin' | 'has-envs' | 'missing'> {
    return this.tx(async (r) => {
      const server = await r.getServer(id);
      if (!server) return 'missing';
      if (server.builtin) return 'builtin';
      if (await r.countEnvsOnServer(id)) return 'has-envs';
      await r.db('servers').where({ id }).delete();
      return 'deleted';
    });
  }
  async deleteEnv(id: string): Promise<'deleted' | 'busy' | 'missing'> {
    return this.tx(async (r) => {
      if (!(await r.getEnv(id))) return 'missing';
      if (await r.db('operations').where({ env_id: id }).whereIn('status', ['pending', 'running']).first()) return 'busy';
      for (const t of ['destructive_approvals', 'releases', 'operations']) await r.db(t).where({ env_id: id }).delete();
      await r.db('environments').where({ id }).delete();
      return 'deleted';
    });
  }
